# 독서로그 — 책의 계보

책이 어떤 책에서 이어졌는지 장르별 가지로 기록하는 웹앱입니다.

- 계정별 저장 (Supabase, Google 로그인 / 카카오 확장 가능)
- 닉네임의 독서로그 · since 표시
- 보기 전용 공개 링크 + QR 코드
- SNS용 JPG 저장 (1:1, 4:5, 전체 지도)
- 네이버 블로그 RSS 연동 (매일 자동 확인 → 리뷰 알림)
- JSON 백업 내보내기 / 가져오기

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조와 디자인 |
| `app.js` | 앱 기능 전체 |
| `config.js` | Supabase 주소·키, 로그인 방식 (직접 채움) |
| `api/sync-blogs.js` | 블로그 RSS 확인 서버 기능 |
| `supabase/schema.sql` | 데이터베이스 구조와 권한 (Supabase SQL Editor에서 1회 실행) |
| `vercel.json` | 공개 주소(/u/...) 연결, 매일 블로그 확인 일정 |
| `vendor/` | Supabase, QR 코드 라이브러리 |

설정 방법은 함께 드린 ‘독서로그 웹앱 설정 가이드’를 따라 주세요.
`config.js`가 비어 있으면 체험 모드(이 기기 브라우저에만 저장)로 열립니다.
